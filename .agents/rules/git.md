# Git & GitHub Rules — Rental PS System (SPEC-GIT-NO-AI)

Aturan ini WAJIB dipatuhi oleh semua agen AI yang bekerja di repositori ini.
Tujuannya: riwayat commit & halaman Contributors GitHub murni atas nama pemilik
dan tim (maksimal 6 peserta), tanpa jejak nama bot/AI.

## 1. Larangan Atribusi AI (RULE-NO-COAUTHOR)
- DILARANG menyertakan trailer berikut di pesan commit:
  - `Co-authored-by: Claude/Cursor/Copilot/Gemini/ChatGPT/...`
  - `Generated by/with AI` atau sejenisnya.
- **Agen AI DILARANG menjalankan `git commit` atau `git push`.** Semua perintah
  git dijalankan manual oleh pengguna di terminalnya sendiri.
- Nonaktifkan fitur "Add AI co-author to commits" di IDE/CLI (Cursor, Windsurf,
  VS Code Copilot, Claude Code, dll).

## 2. Identitas Git (RULE-GIT-CONFIG)
Identitas lokal repo wajib nama & email GitHub pribadi (bukan nama bot/AI):
```bash
git config user.name "Nama Lengkap"
git config user.email "email-github@domain.com"
git config --list
```
Status repo saat ini: `ayubwicak <ayubwicak@gmail.com>` (sudah benar — jangan diubah tanpa persetujuan pemilik).

## 3. Git Hook Penjaga (RULE-GIT-HOOK)
File `.git/hooks/commit-msg` (aktif, executable) otomatis menghapus baris
atribusi AI dari pesan commit. Jangan menghapus/menonaktifkan hook ini.
Jika hook hilang (mis. clone baru), pasang ulang skripnya dan jalankan
`chmod +x .git/hooks/commit-msg`.

## 4. Format Pesan Commit (RULE-COMMIT-FORMAT)
Gunakan Conventional Commits, deskriptif seperti alur kerja developer manusia:
- `feat(sesi): tambah dukungan mode paket 3 jam`
- `feat(booking): validasi bentrok jadwal unit`
- `ui(dashboard): tambah grafik pendapatan mingguan`
- `fix(kasir): perbaiki perhitungan diskon poin member`
- `fix(realtime): atasi event sync_data ganda saat pause sesi`
- `docs(readme): perbarui panduan instalasi dan profil tim`
- `chore(deps): naikkan better-sqlite3 ke ^13.0.0`

## 5. Prosedur Staging, Commit & Push (WORKFLOW-GIT-PUSH)
Dijalankan MANUAL oleh pengguna (bukan agen AI):
```bash
git status                                   # pastikan tidak ada file log/prompt AI
git add <file-spesifik>                      # tambah file spesifik, hindari `git add -A` buta
git commit -m "feat(scope): deskripsi"       # pesan standar, tanpa atribusi AI
git log -n 3 --pretty=format:"%h - %an <%ae> : %B"   # audit author & pesan
git push -u origin main
```
File konfigurasi AI lokal dilarang ikut ter-commit — sudah diblokir via `.gitignore`
(`.cursor/`, `.cursorrules`, `.claude/`, `.aider*`, `.copilot*`, `*.ai.md`).

## 6. Pembersihan Riwayat (RULE-GIT-CLEANUP)
Jika atribusi AI terlanjur masuk:
```bash
# Commit terakhir, belum di-push
git commit --amend --author="Nama <email@domain.com>"   # hapus baris Co-authored-by di editor, simpan

# Seluruh riwayat branch
git filter-branch -f --msg-filter 'sed -E "/Co-authored-by:/Id"' HEAD
```
Cabut juga atribusi author/committer bila nama AI terlanjur tercatat
(`git filter-branch --env-filter ...`), lalu push `--force-with-lease` hanya jika
disetujui pemilik repo.
